# TROPA DA RÚSSIA — Frontend oficial (TDR • GTA Roleplay)

Frontend React + TypeScript + Vite + Tailwind + Motion. Catálogo oficial, carrinho, calculadora de preços, formulário de encomenda, revisão e tela de integração pendente. Sem backend nesta etapa.

```bash
npm install
cp .env.example .env    # defina VITE_DISCORD_INVITE_URL
npm run dev
npm test
npm run build
```

Documentação completa para o backend: **FRONTEND_INTEGRACAO_ARENA.md**.
